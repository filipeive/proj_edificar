# Princípios de UI — Portal Life Church

> Princípios que guiam todas as decisões de interface deste projeto.

---

## 1. Mobile First, Always

Toda interface é desenhada primeiro para 320px e expandida progressivamente.
Nenhum conteúdo essencial pode ficar oculto em mobile.

## 2. Clareza > Decoração

Informação clara e hierarquia visual forte são mais importantes que efeitos visuais.
Se um elemento não ajuda o utilizador a completar a tarefa, não deveria existir.

## 3. Consistência Absoluta

O mesmo componente deve ter o mesmo aspeto em todas as páginas.
Botões, cards, badges, inputs — todos seguem o Design System documentado.

## 4. Performance é UX

Cada milissegundo conta. Nada de CDN runtime, CSS inline em massa, ou JS bloqueante.
O utilizador deve perceber o sistema como instantâneo.

## 5. Acessibilidade é Obrigatória

Contraste mínimo 4.5:1. Touch targets ≥ 44px. Labels em todos os inputs.
ARIA labels em elementos interativos. Teclado navigável.

## 6. Feedback Contínuo

Toda ação do utilizador deve ter feedback visual imediato.
Loading states, success messages, error states, empty states — todos padronizados.

## 7. Profissionalismo SaaS

O produto deve competir visualmente com os melhores SaaS do mercado.
Referências: Linear, Notion, Vercel, Stripe Dashboard.
